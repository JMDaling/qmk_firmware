# JMD: Flashing instructions

Build with:
qmk compile -kb keychron/k6_pro/ansi/rgb -km default

Flash with:
qmk flash -kb keychron/k6_pro/ansi/rgb -km default


Lately I have flashed directly, not building the firmware, I think building is not required as it builds during flash, eitherways the changes were applied

Flash procedure: To put the keyboard in flashmode, switch it off, hold in the ESC key while swithing it on, then on the laptop run the flash command in the terminal.

Note: There is also a flash/reset button under spacebar
